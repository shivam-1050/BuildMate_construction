# 🏗️ BuildMate – Construction Materials Website

BuildMate is a **responsive construction materials business website** developed using **HTML5 and CSS3**. The website is designed to present construction materials such as **sand, aggregate, soil, and bricks** in a clean and professional way.

The project demonstrates how a modern business landing page can be created using basic frontend technologies.

## 🌐 Project Overview

The website provides customers with information about construction materials, company services, pricing advantages, and a contact form for requesting a quotation.

### Main Products

* 🏖️ Sand
* 🪨 Aggregate
* 🌱 Soil
* 🧱 Bricks

The product section presents each material with a short description and a responsive card-based layout.

## ✨ Features

* Responsive navigation bar
* Professional hero/landing section
* Construction materials product section
* "Why Choose Us?" section
* About BuildMate section
* Free quotation/contact form
* Responsive design for desktop, tablet, and mobile
* Smooth scrolling navigation
* Hover effects on buttons and product cards
* Modern card-based UI
* Mobile-friendly layout using CSS media queries

The website uses responsive breakpoints at **900px and 600px** to adapt the layout for different screen sizes.

## 🛠️ Technologies Used

* **HTML5** – Website structure and semantic content
* **CSS3** – Styling, layout, animations, and responsive design
* **CSS Grid** – Product and feature layouts
* **CSS Flexbox** – Header and hero-section alignment
* **Media Queries** – Responsive design
* **Unsplash Images** – Background and construction images

## 📄 Website Sections

### 1. Header & Navigation

The website contains a sticky navigation bar with links to:

* Home
* Products
* About
* Contact

### 2. Hero Section

The hero section introduces BuildMate with a construction-focused message and two call-to-action buttons:

* **Get a Quote**
* **View Products**

### 3. Products

The product section displays four construction materials:

* Sand
* Aggregate
* Soil
* Bricks

Each product is presented in a separate card.

### 4. Why Choose Us?

This section highlights three important business advantages:

* Quality Materials
* Best Prices
* Fast Delivery

### 5. About

The About section describes BuildMate as a sample construction-material business website and explains its goal of providing reliable construction materials and delivery services.

### 6. Contact / Get a Free Quote

The contact section includes a form where users can enter:

* Name
* Phone Number
* Email
* Material requirements/message

## 📱 Responsive Design

The website is designed to work on:

* 💻 Desktop
* 💻 Laptop
* 📱 Tablet
* 📱 Mobile

CSS media queries change the product grid, feature layout, hero text size, navigation, and section spacing according to screen size.
